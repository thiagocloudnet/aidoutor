# AIDoutor

**Agente inteligente de engenharia de software do ecossistema Thiago.Cloud.**

Projeto em estruturação, concebido para apoiar análise de código, documentação, revisão de segurança, testes e evolução de aplicações modulares.

## Direção do projeto

- Engenharia de software com Python.
- Modelagem e análise de dados com PostgreSQL.
- Arquitetura de interfaces HTML5, CSS3, JavaScript e AJAX.
- Planejamento e acompanhamento de desenvolvimento.
- Memória e pesquisa vetorial propostas com pgvector, dependentes de modelos de embeddings e inferência configurados separadamente.

O AIDoutor é proposto como subsistema independente do núcleo UPCode Framework. A arquitetura pretendida prioriza Python sem Django, Flask ou FastAPI como base, permitindo bibliotecas especializadas para segurança e PostgreSQL.

## Estado atual

Este repositório contém somente a apresentação pública. As capacidades descritas são objetivos, não funcionalidades comprovadas nesta publicação. A implementação será mantida em repositório privado separado, `ai-doutor`.

Alterações críticas propostas pelo agente deverão passar por revisão e aprovação. Credenciais, código privado e informações de clientes não integram este espaço público.
